# 交火 · 更新、安装与备份流程

> 最后更新：2026-11-08（v3.6.2）  
> 适用范围：《交火 · 户型图红蓝对抗》四个页面（主页 / 整备大厅 / 战役 / 长街尸潮）  
> 目标：以后每次更新都按同一套路径走，不漏发版、不漏装安装点、不漏备份 zip。

## 1. 每次更新固定顺序

### 1.1 改版本号

`VERSION.txt` 是唯一权威，以下位置必须一起改（`tests/version_test.js` 会逐处比对）：

1. `VERSION.txt`：`vX.Y.Z`
2. `index.html`：4 处图签栏 `REV. 版次`
3. `game/hub.html`：1 处
4. `game/street.html`：1 处
5. `game/breach.html`：`setTitleBlock` 里 `kind === 'rev'` 的注入值
6. `package.json`：`"version": "X.Y.Z"`（不带 `v`）
7. `CHANGELOG.md`：新增 `## [vX.Y.Z] — YYYY-MM-DD · 摘要`
8. `README.md`：顶部「当前版本」与打包示例文件名
9. `AI_README.md`：顶部「当前构建版本」与发布包名
10. 四页主脚本开头的 GitHub Pages 缓存版本号（`var v = '3.6.2'`，发新版必须同步）

补丁走 `PATCH`（如 v3.5.0 → v3.5.1），功能走 `MINOR`（如 v3.4.1 → v3.5.0）。

### 1.2 跑检查

在 `W:\AI Code DSH\交火_游戏` 下：

```powershell
node .uiwork\ui_check.js
node tools\check-site.js
node tests\version_test.js
node tests\doc_test.js
node tests\offline_test.js
```

再逐个跑 25 个断言测试。`tests\run_all.js` 在本机沙箱里可能因管道 EPERM 误报，逐个单跑最稳：

```powershell
$order = 'offline_test.js','version_test.js','doc_test.js','preview_test.js','protocol_test.js',
'account_test.js','board_test.js','cover_test.js','render_test.js','smoke_test.js',
'input_state_test.js','shotgun_test.js','combat_test.js','feature_test.js','tutorial_test.js',
'hub_test.js','newfeatures_test.js','fire_acc_test.js','squad_test.js','street_test.js',
'meta_test.js','maps_test.js','path_test.js','wall_test.js','perf_test.js'
foreach ($t in $order) { node "tests\$t"; if ($LASTEXITCODE -ne 0) { throw "测试失败: $t" } }
```

要求：25/25 全绿，`UI CHECK PASSED`、`SITE CHECK PASSED`、`OFFLINE AUDIT PASSED`。

### 1.3 打安装包

GitHub Release 和本地安装统一用**瘦包**（不含 187 MB 的 WebView2 离线安装器，约 0.66 MB）：

```powershell
cd "W:\AI Code DSH\归档\交火_游戏_v3.5.1_源包"
powershell -NoProfile -ExecutionPolicy Bypass -File .uiwork\build-package.ps1 `
  -NoWebView2 -OutDir "W:\AI Code DSH\归档\发布包"
```

得到 `W:\AI Code DSH\归档\发布包\交火_vX.Y.Z.zip`。

需要完全离线装 WebView2 时才打全量包（去掉 `-NoWebView2`，包会到 180 MB 左右）；日常 Release 不用。

### 1.4 备份 zip 到 W:\zip

**每次更新都必须做。** 保留历史版本，不要覆盖旧版本；同一版本重打时才覆盖同名文件。

```powershell
$v = 'vX.Y.Z'
Copy-Item "W:\AI Code DSH\归档\发布包\交火_$v.zip" "W:\zip\交火_$v.zip" -Force
```

发布到 GitHub 还要在归档目录留一份 ASCII 名，避免 GitHub 把中文附件名替换成下划线：

```powershell
Copy-Item "W:\AI Code DSH\归档\发布包\交火_$v.zip" `
          "W:\AI Code DSH\归档\发布包\jiaohuo_$v.zip" -Force
```

### 1.5 安装到 Z 盘和 G 盘

先解压瘦包到临时目录，再调用包里的 `install.bat`。安装器支持 `CF_DIR` / `CF_YES` 环境变量，适合自动安装：

```powershell
$v = 'vX.Y.Z'
$zip = "W:\AI Code DSH\归档\发布包\jiaohuo_$v.zip"
$stage = Join-Path $env:TEMP "jiaohuo-install-$v"
if (Test-Path $stage) { Remove-Item $stage -Recurse -Force }
Expand-Archive -Path $zip -DestinationPath $stage -Force
$src = Join-Path $stage "交火_$v"

$env:CF_YES = '1'

# Z 盘：大厅的「交火」槽位
$env:CF_DIR = 'Z:\Root\game\breach'
Push-Location $src
cmd /c install.bat
Pop-Location

# G 盘：独立安装
$env:CF_DIR = 'G:\Fire'
Push-Location $src
cmd /c install.bat
Pop-Location

Remove-Item Env:CF_DIR, Env:CF_YES -ErrorAction SilentlyContinue
Remove-Item $stage -Recurse -Force
```

安装器会做四件事：检查 WebView2、复制游戏本体、写 `VERSION.txt`、创建桌面快捷方式。桌面快捷方式始终指向**最后一次安装的目录**（按上面的顺序就是 `G:\Fire`）。

### 1.6 装完验证

```powershell
foreach ($p in 'Z:\Root\game\breach', 'G:\Fire') {
  "== $p =="
  Get-Content (Join-Path $p 'VERSION.txt')
  Test-Path (Join-Path $p 'index.html')
  Test-Path (Join-Path $p 'game\breach.html')
  Test-Path (Join-Path $p 'fontawesome-free-7.3.1-web\css\all.min.css')
}
```

两处 `VERSION.txt` 必须等于本次版本。涉及移动端时，再确认安装目录的 `game\breach.html` 含 `mobRotate` / `mobPortrait`，并实际用手机横竖屏各开一次。

### 1.7 发布到 GitHub

**只在明确说「发版 / 上传 Git」时执行。** 发布脚本会用根提交 force 覆盖 `main`，并把快照上传、触发 Pages、创建 tag/Release、上传 `jiaohuo_$v.zip`。

```powershell
cd "W:\AI Code DSH"
node .dsh-publish\sync-repo.js
node --use-system-ca .dsh-publish\publish-node.js
```

`sync-repo.js` 按 `.gitignore` 从 `交火_游戏` 重建 `.dsh-publish/repo/breach-door-cqb`，不会带入 WebView2 安装器、zip、完整 FontAwesome 发行包。发布脚本读快照的 `VERSION.txt` 和 `归档\发布包\jiaohuo_$v.zip`。

发布后检查：

- `https://endlessfield.github.io/breach-door-cqb/` 页面图签栏是本次版本
- `https://github.com/EndlessField/breach-door-cqb/actions` 的 Pages 工作流成功
- Release 附件是 ASCII 名 `jiaohuo_vX.Y.Z.zip`
- `main` 最新提交是 `release: vX.Y.Z（交火 · 户型图红蓝对抗）`

## 4. 注意

- **不要**把 `index.html` 单独拷到 Z 盘根目录，也不要覆盖大厅的 `games.json`。
- **不要**把 WebView2 安装器或 zip 提交进 Git；`.gitignore` 已排除，但仍要在提交前扫一眼。
- 发布附件必须用 ASCII 名（`jiaohuo_vX.Y.Z.zip`），GitHub 会把中文附件名替换成下划线。
- 安装器会保留目标目录里的导出存档等外部文件；不要为了“干净”手动删玩家数据。
- `W:\zip` 只增不改：历史版本保留，方便回退。
- 桌面快捷方式指向最后安装的目录；Z 盘大厅用户从 `游戏大厅.exe` 的「交火」卡片进入。
